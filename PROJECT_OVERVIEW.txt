II. Executive Summary
MACMort is a modern, native macOS application developed using Swift, SwiftUI, and AppKit. It provides a real-time, transparent floating overlay over any target window (games, manga readers, visual novels, or web browsers) that automatically detects Japanese text on screen and overlays fluent English translations directly in place. The project incorporates high-performance native macOS frameworks including ScreenCaptureKit, Vision, and Apple Translation, coupled with a local SQLite caching engine and optional DeepL API integration. It showcases advanced system integration, multi-threaded asynchronous network and ML operations, custom window management (click-through floating HUD), dynamic settings, and robust onboarding and permissions handling.

IV. Technical Architecture and Advanced Features
A. High-Performance Screen Capture & Computer Vision
• ScreenCaptureKit Integration: Efficiently captures frames at up to 20 FPS directly from the display subsystem. Employs frame-skipping algorithms to eliminate redundant OCR processing when screen content is static.
• Vision Framework OCR Pipeline: Employs Apple's Vision ML engine configured for Japanese text recognition. Tracks text bounding coordinates and converts vision normalized coordinates into AppKit/SwiftUI view space.
• Dynamic Background Color Sampling: Samples surrounding pixel colors around detected text blocks to render matched background patches, cleanly obscuring original Japanese text before displaying translated text on top.

B. Multi-Tiered Translation Engine & State Management
• Layered Caching & Offline-First Strategy: First checks an instant, local SQLite database for existing translations; falls back to Apple's native on-device Translation framework (macOS 15+) for zero-latency, private, offline execution; and optionally routes to DeepL API when configured.
• Asynchronous Architecture: Uses Swift Concurrency (async/await, Task, MainActor) and Combine to process screen frames, run ML inference, perform database/network lookups, and update UI without blocking the main rendering thread.
• Global Hotkey & Window Management: Implements system-wide keyboard shortcuts via Accessibility APIs, allowing seamless HUD toggles (⌥⌘H) and pass-through mouse click handling (⌥⌘X) while external games or applications remain in focus.
